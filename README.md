# Sales Data Analysis Project

## Project Overview

This portfolio project analyzes a sample sales dataset to identify trends in revenue, profit, products, customers, categories, and regions.

The project demonstrates practical data analysis skills using **Excel, SQL, and Power BI-ready data preparation**.

## Business Objectives

- Analyze overall sales and profitability
- Identify the best-performing products and categories
- Compare regional sales performance
- Analyze monthly sales trends
- Identify high-value customers and orders
- Calculate key performance indicators (KPIs)

## Tools & Technologies

- **Microsoft Excel** – Data analysis, pivot-style summaries, KPI dashboard, and charts
- **SQL** – Business analysis queries and aggregations
- **Power BI** – Dashboard design plan and Power BI-ready dataset
- **GitHub** – Project versioning and portfolio presentation
